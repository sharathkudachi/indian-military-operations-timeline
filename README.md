IN Indian Military Operations — Interactive Timeline

[View Live](https://sharathkudachi.github.io/indian-military-operations-timeline/)

🛰️ Project Overview

Indian Military Operations — Interactive Timeline is a visually rich, interactive web application that presents major Indian military battles and strategic operations from 1947 to modern times.
The project combines military history, interactive data visualization, and a futuristic HUD-style user interface to create an educational and engaging experience.
It is designed to be lightweight, fast, and fully client-side — requiring no backend server.

✨ Key Features

⚔️ Interactive Military Timeline

Chronological visualization of battles and operations
Vertical and Horizontal timeline modes
Smooth animations and transitions

🔎 Smart Search & Filtering

Search by battle name
Search by year
Search by location
Search by detailed description

🪖 Branch-Based Filtering

Indian Army
Indian Navy
Indian Air Force
Joint Operations

🗺️ Geographic Visualization

Interactive maps using Leaflet.js
Location markers for each operation
Dynamic zoom and focus

🎥 Embedded Educational Videos

Documentary and explainer video embeds
Contextual learning support

🎛️ Military HUD User Interface

Camouflage military color palette
Radar sweep animation background
Hex-grid futuristic design
Glass panel UI elements
